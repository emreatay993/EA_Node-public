# Notices and scope

## SKF references and name

This project is an independent engineering implementation based on publicly available SKF equations and tables. It is not developed, approved, certified or supported by SKF. SKF and SKF Explorer are trademarks of their respective owner.

The application does not contain an SKF bearing catalogue database and does not infer hidden internal geometry. Product dimensions, ratings, equivalent-load factors, limiting speeds and installation limits must be checked against current supplier data.

## PyQt6 licensing

The source package does not redistribute PyQt6 binaries. PyQt6 is installed separately as a dependency and is available under GPL/commercial licensing from Riverbank Computing. Review the applicable licence before distributing a compiled or bundled application.

## Model status

Published SKF/ISO equations and engineering extensions are separated in source modules, GUI notes, warnings and reports. The thermal network, local contact-temperature resistances, installation multipliers, generic rolling-element load distribution, graph digitization and Explorer scaling require validation for the actual bearing arrangement.
